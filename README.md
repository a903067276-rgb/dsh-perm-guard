# dsh-perm-guard

[English](README.md) | [简体中文](README.zh-CN.md)

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)

A **permission management plugin** for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) web — manage and guard session permission presets.

> 🚧 **Work in progress.** This repository is the scaffold for the plugin.
> The concrete feature set is being designed. See the [中文 README](README.zh-CN.md) for the intended direction.

## Intended direction

- View and manage the permission preset currently applied to a session (e.g. `workspace-write`, `danger-full-access`, custom presets)
- Guard rails around permission escalations — see clearly what an escalation would unlock before approving it
- Per-session or per-workspace permission policy, surfaced in the Web UI
