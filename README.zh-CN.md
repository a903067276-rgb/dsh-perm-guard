# dsh-perm-guard

[English](README.md) | [简体中文](README.zh-CN.md)

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)

面向 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh`）web 的**权限管理插件**——管理和守卫会话权限档位。

> 🚧 **开发中。** 本仓库当前是插件骨架，具体功能正在设计中。方向见下文。

## 设计方向

- 查看和管理会话当前应用的权限预设（如 `workspace-write`、`danger-full-access`、自定义预设）
- 权限升级的守卫——批准前清楚看到这次升级会解锁什么
- 按会话 / 按工作区的权限策略，在 Web 界面中呈现
